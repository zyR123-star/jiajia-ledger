# 佳嘉记账

两个人只读互看的记账 PWA。收入、支出、分类、账户和备注可以保存在本机，也可以连接 Supabase 在双方设备之间同步。

> 吉祥物「小金币」与多多的云朵共用同一套表情和描边，以暖黄、蓝色星芒和粉色爱心形成对应关系。

正式网址：https://zyr123-star.github.io/jiajia-ledger/

## 使用

双击 `start-jiajia.cmd` 会打开正式网址；本地开发可运行 `node tools/server.cjs`。

在 Edge 或 Safari 中可以把页面安装到桌面或主屏幕。第一次联网打开后，Service Worker 会缓存页面，断网也能继续记账。

## 共享权限

- 每条账单由创建者选择“仅自己”或“对方可见”，默认仅自己。
- 对方可见账单只允许对方查看，不允许对方修改、删除或变更权限。
- 私密账单由数据库行级权限拦截，不会同步到对方设备。
- 首页和统计只汇总当前账号实际有权查看的账单。
- 明细页可在“双方 / 我的 / 对方”之间切换，也可以从配对信息直接打开对方共享账本。
- 每次打开记账弹层会生成固定账单 ID，连续点击和网络重试不会重复写入。
- 对方共享账单昵称固定显示为“多多”。
- 手机端登录会话同时使用 localStorage 和 IndexedDB 备份，降低 Safari 清理存储后掉登录的概率。

## 共享服务

共享服务已经在 `config.js` 中预先配置，默认连接项目 `jiajia-duoduo-ledger`。

1. 打开佳嘉记账的“设置 → 共享账本”。
2. 注册并登录自己的账号。
3. 一方把 6 位配对码发给另一方完成配对。

不要把 `service_role` key 填进应用。应用只需要 Project URL 和 anon public key。
多多钱包也使用同一份数据库脚本；两个应用只需在同一个 Supabase 项目执行一次。

## 本机与云端

- 未连接 Supabase 时，使用本机 IndexedDB 账本。
- 登录后切换到共享账本；退出登录后回到本机账本，两套数据不会混在一起。
- 云端模式下会缓存当前账号有权查看的账单，断网时可以浏览，联网后每 15 秒自动检查新数据。

## 数据

- 完整备份：设置页导出 JSON。
- 表格导出：设置页导出 CSV。
- 恢复：设置页选择 JSON；恢复前会确认，并用备份替换当前账单。
- 本机模式的数据只存在当前浏览器；云端模式以 Supabase 数据库为准。
- 清理浏览器网站数据会清空本机账本和登录缓存，定期导出备份。

## 注册说明

- 不需要 GitHub 账号，普通用户使用邮箱和密码注册。
- 当前已关闭强制邮箱验证，注册成功后会直接登录，不再等待确认邮件。
- 邮箱必须能正常收信，不要填写昵称、手机号或保留测试域名。

## 文件

- `index.html`：页面结构与图标。
- `styles.css`：浅色、深色和移动端布局。
- `app.js`：记账、统计、筛选、备份与导入。
- `cloud.js`：Supabase 登录、配对和共享账单接口。
- `supabase/schema.sql`：数据库表、配对函数和行级权限。
- `supabase/migrations/`：已推送到真实 Supabase 项目的迁移记录。
- `sw.js`：离线缓存。
- `tools/server.cjs`：本地静态服务。
